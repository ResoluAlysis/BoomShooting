### “敌人”：

<img width="456" height="765" alt="f96dd8b3fa439fb011acb140dfff12d1" src="https://github.com/user-attachments/assets/203136f7-624b-4ac1-ba1e-92d436307ccc" />

这个黑色方块就是“敌人”（也叫做“有效目标”），在首次命中目标时会进入 “锁定” 状态（会有醒目的红框标记），并基于命中刻计算额外得分；

锁定时间为 5s ，每次命中“锁定目标” +0.4s 锁定时长，若未命中任何 “有效目标” 时立刻打断锁定，当锁定时间结束后自动结算分数。

>（公式为：总分 = 命中次数 * 得分倍率，得分倍率 = 移速 + 转速 - 1）

被“敌人”碰撞时（非无敌模式下）立刻结算游戏并暂停计时，游戏结束后无法再获得分数与触发 “锁定” 状态...此时需要按住 左CLRT+R 复原游戏

# 依旧一些碎碎念

游戏的最初想法源于：“我希望实现子弹命中目标时屏幕可以向子弹飞行方向震动，以此实现更强的打击感...”

基于 **Unity** 开发，最终耗时 **两天半** （认真.JPG）

所有特效、子弹（视觉元素）均使用 **Unity** 的 **ParticleSystem** 制作，特效的生成与回收由专门的 **“特效对象池”** 统一管理...

>该对象池的功能不仅仅是生成与回收，也负责所有特效预制体的计时工作（使用协程异步计算，可通过Unity Inspector管理所有预制体的存在时间），这样可以省去为每一个特效预制体装配脚本并调试参数的工作...

相机控制器结合了 **Unity Cinemachine** 来控制主相机，并设计了数据结构以保存 **“自定义的震动”** 曲线，实现了 “命中不同物体时能有不一样的震感” ，并编写了独特的震动算法使得观感达到最佳（如连续震动、震动切换）...
